# ADAA | SlackQuant — Public Research Dashboard v0.1

Static, offline-capable research interface for **Diversify the Decisions, Not Just the Assets**.

## Branding

The public interface is branded **ADAA | SlackQuant**. SlackQuant is the interface/research-brand layer only; the canonical paper title, authorship, scientific freeze, replication files, and research results are unchanged.

## Open locally

Double-click `index.html`. No Python/R server and no internet connection are required.

## Deployment

The directory can be published as-is on GitHub Pages or any static host. Keep the directory structure intact.

## Source-of-truth rule

This dashboard is presentation only. Data are copied from the rights-safe `ADAA_Public_Replication_Package_v1.0.2.zip`; the interface does not download data or re-run strategy logic. See `DASHBOARD_DATA_CONTRACT_v0.1.md` and `DATA_MANIFEST_SHA256.csv`.

## Included downloads

- `downloads/ADAA_SSRN_Working_Paper_v1.17_FINAL_PUBLIC_RELEASE.pdf`
- `downloads/ADAA_Public_Replication_Package_v1.0.2.zip`

## Live links

- Dashboard: https://slackquant80.github.io/adaa-slackquant/
- Public replication repository: https://github.com/slackquant80/adaa-decision-diversification
- Archived replication release (v1.0.2): https://doi.org/10.5281/zenodo.21853533

## Scope

No live signals, no current holdings, no portfolio recommendation, and no dashboard-side optimizer.
